# 🐑 X-Sheep is back

**L'Espoir en Action**
*Par Emmanuel Payet*

## Installation

```bash
npm install
npm run dev
```

## Contrôles

- **Clavier** : ESPACE (sauter), W (voler), Flèches (bouger)
- **Souris** : Clic + Glisser (mouvement libre), Double-clic (vol)
- **Tactile** : Touch + Glisser (mouvement libre), Double-tap (vol)

## Mission

Sauver des vies avec l'espoir authentique.

## X-Sheep — L’ascension

La refonte verticale est disponible dans [`public/ascension/`](public/ascension/).
Elle propose une aventure au jetpack avec mines à mémoriser, bonus contre les boss,
sauts interstellaires, un mode infini, des sons spatiaux et 15 langues.

- En local : ouvrir `public/ascension/JOUER.html` (fichier autonome).
- Avec Vite : ouvrir `/X-Sheep/ascension/` sur le serveur de développement.
- Après intégration et déploiement GitHub Pages : `/X-Sheep/ascension/`.

Le jeu historique reste à la racine. Les traductions de la refonte sont une
première version à relire, notamment pour l’humour, le créole et le lingala.
